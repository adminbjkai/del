Help

Applications

Status
Runtime state DEL last correlated:
  • running / active — up now
  • stopped / exited / inactive — installed but not running
  • paused / unknown — held or unclear
Warnings
Weak associations (ownership enum possible, or confidence band possible — score under 60). Probable (≥60) is a strong claim. Review weak rows before planning — not an app health check.
Protected
DEL will not build a removal plan (e.g. DEL itself).
Installed
Best install-time signal in Eastern time: container Created, directory age, or first discovery.
Kind
Primary runtime: compose, container, systemd, …

View Apps

Online
The domain is in an enabled Nginx site from the latest completed scan and returned an HTTPS response below 500. DNS, TLS, routing, and an answering upstream all worked.
Unavailable hidden
An enabled inventory domain failed its live HTTPS check or returned a 5xx response, so it is intentionally absent from the launchpad.
Categories
DEL supplies an initial category. Customize it per card; your override is saved only in this browser.
My order
Open Customize, drag cards, then choose My order. Stars, hidden cards, card size, spacing, and view mode are also browser-local.

Owner apps & sharing

Owner app(s)
App(s) DEL attributes this resource to. unassigned = no claim (see Orphans).
Shared
Used by more than one app. Removal of one app must not delete shared resources.

Containers — State / health

State
Docker runtime: running, exited, paused, restarting, …
Health
Docker healthcheck when defined: healthy / unhealthy / starting. no healthcheck means none configured — not a failure.

Images

Dangling
Untagged <none>:<none> leftover after rebuild — often reclaimable if unused.
Used by
How many containers reference this image.

Volumes

Orphan (resources tab)
No container currently mounts this volume.
Shared
Associated with more than one app.

Networks

Shared
Used across apps/projects. Built-ins (bridge/host/none) are never removed.
Attached
Containers currently on this network.

Directories & git

Dirty
dirty = uncommitted git changes; clean = clean tree; — = not a repo / unknown.
Size
Approximate on-disk size (du).

Nginx sites

not enabled
Config exists but is not in sites-enabled — not serving.
ssl
Config references a TLS certificate.

Orphans page

Unassociated
Resource has zero rows in the associations table for any app.
Actionable
Default view. Real review candidates: custom systemd units, unused volumes, dangling/unused images, enabled nginx with no app, project dirs/git/.env with no owner, listeners tied to untracked app units.
System
OS/vendor noise — not abandoned apps. Examples: NetworkManager, sshd:22, Samba, distro cron/timers, Docker built-in networks. Hidden unless you choose “Show system & expected too”.
Expected
Situations that look unassociated but are intentional: parked (disabled) nginx configs; images still declared by a compose project that isn’t running.
Why listed
Per-row explanation of the classification — read this before deleting anything.

Jobs

dry-run
Simulates every step; changes nothing on the host.
LIVE
Executes real helper operations (with safety gates).
success / failed / refused
Terminal outcomes. refused = a gate blocked the run.

Table filters

Quick filter
Top search box — matches any column. Shortcut: /.
Column filter
Excel-style: open the filter under a header to pick from a checkbox list of existing values (select all / clear), and/or use text operators (contains, does not contain, equals, starts with, …).
Clear all filters
Resets every column filter and the quick filter at once.

Assistant

Read-only
The assistant has no tools and cannot change anything. Removal still goes through an app's plan/confirm flow.
Scope
What the model is told about: the whole server, one application, the orphan list, one resource type, or a single resource.
Context truncated
The inventory facts were cut to the configured budget; the answer may miss items. Narrow the scope for full coverage.
Privacy
Inventory metadata (names, paths, tags, ports, evidence) is sent to Ollama Cloud. File contents, env values and secrets never are.

Times

Eastern (New York), compact MM-DD-YY H:MM AM/PM (e.g. 05-13-26 7:31 AM).
