It answers questions about the inventory using a hosted model (Ollama Cloud) and needs an API key. To enable it:

  1. Save the key, one line, readable by the DEL user only: install -m 600 /dev/stdin /apps/del/config/ollama-api-key.txt <<< "<key>" (the file is refused if it is group- or world-readable).

  3. Restart the service: systemctl restart del-web.
  4. Open Settings → Assistant and click Test connection.
