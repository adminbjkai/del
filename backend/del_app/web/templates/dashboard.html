The operator loop

how a removal goes, start to finish
  1. Run a scan from the scan stamp at the bottom of the sidebar (or Ctrl K, Run a new scan). The stamp shows when it finished.
  2. Open Applications and review warnings and possible (weak) mappings before you plan. Protected apps have no plan.
  3. Check Resources: owner chips are current apps; shared means more than one app or a system path, and it is never deleted with a single app.
  4. Review Orphans. Read why each row is listed; nothing is deleted from that page.
  5. Ask the assistant from the right rail when unsure. It is read-only.
  6. On the app page, Plan removal, run it as a dry run, then live. Follow it on Jobs. Remove app now skips the review; use it only when you mean it.
