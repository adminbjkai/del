Host inventory at a glance. Work the loop below; jump from stats when something is already on fire.

shared = 2+ current apps probable = strong owner possible = weak unassigned → Orphans Ask = read-only

How to use DEL
  1. Press Run scan now in this panel. Wait until the scan strip shows done. Scan config lives under Settings → Scanning.
  2. Open Applications. Review warnings and possible (weak) mappings before you plan. Protected apps have no plan.
  3. Open Resources → Containers, then the other tabs. Owner chips = current apps; shared = more than one current app (do not delete with a single app).
  4. Open Orphans (actionable view). Review-only — there is no delete on that page. Read Why listed; Ask the row if unsure.
  5. Use the right-rail Ask tab (or an Ask chip). Read-only; it cannot plan or remove.
  6. On the app page, Plan removal — not “Remove app now (skips review)” unless you mean it. Dry-run first on the plan, then LIVE. Track it on Jobs.
