Host inventory at a glance. Work the loop below; jump from stats when something is already on fire.

How to use DEL

  1. Press Run scan now in this panel (or the same control under Recent scans / Settings → Scanning). Wait until the scan strip shows done.
  2. Open Applications. Sort/filter on warnings and uncertain mappings before you touch a plan.
  3. Open Resources → Containers, then the other resource tabs. Check owner app(s) and shared flags.
  4. Open Orphans (actionable view). Read “why listed” on the row before any delete.
  5. Select the right-rail Ask tab (mobile: Ask FAB). Type in the composer — read-only; it cannot remove anything.
  6. On an app page, build a removal plan. Confirm on Jobs: dry-run first, LIVE only if the plan matches what you intend.
