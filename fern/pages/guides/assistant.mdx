The **Assistant** is a read-only chat over the latest DEL inventory: the full page
at `/assistant`, and the **Ask** tab of the Help|Ask right rail on every other
authenticated page (page-scoped defaults from the current route). It uses
**Ollama Cloud** (`glm-5.3-flash`). It cannot run commands, change the host, or
build a removal plan. Plans still go through Applications → plan → job.

## What you can ask

Typical path is the [operator loop](/guides/sop): scan → apps → resources →
orphans → this assistant → [remove](/guides/removing-an-application).

Pick a **scope**, then click a suggested question (label + description) or type your own:

<AccordionGroup>
  <Accordion title="General">
    Whole-server summary, stale apps, shared resources, complete owner index (every volume/image/network/container), protected apps.
  </Accordion>
  <Accordion title="Application">
    Pieces, blast radius, backups, `all_owners` / `also_owners` on shared rows, go/no-go if protected.
  </Accordion>
  <Accordion title="Orphans">
    Review-only. Cluster, lowest-risk to investigate next, possible correlation misses. Never delete from `/orphans`.
  </Accordion>
  <Accordion title="Resource type / resource">
    Images, containers, networks, volumes as a class, or one key: owners, shared, data-loss. Never “safe to delete” if shared.
  </Accordion>
</AccordionGroup>

Suggested prompts are the same library for every operator. Deep links from an app
page, Orphans, or a Resources row pre-select the matching scope.

## What it sees

Only inventory metadata DEL already stores: names, paths, image tags, ports,
association confidence, shared/owners, evidence strings. **Not** file contents,
`.env` values, secrets, or job output.

Answers are grounded in that snapshot. If something is missing from the scan,
the assistant should say so rather than guess.

## Enablement

1. Write the Ollama Cloud key to `/apps/del/config/ollama-api-key.txt` mode `0600`.
2. Keep `[assistant] enabled = true` in `config/del.toml` (default).
3. `systemctl restart del-web`
4. Settings → Assistant → **Test connection**

Without a key the page explains how to enable it; the API returns 503.

See `docs/ASSISTANT.md` for the architecture contract.
